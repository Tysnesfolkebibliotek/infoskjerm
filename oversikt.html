    Tilgangsnøkkel for å lagre

    Alle kan sjå sida, men berre den som har ein tilgangsnøkkel kan lagre endringar. Nøkkelen blir lagra i denne nettlesaren.

    Slik lagar du ein nøkkel:

    1. Logg inn på GitHub som Tysnesfolkebibliotek og gå til github.com/settings/personal-access-tokens/new.
    2. Gi han eit namn, til dømes «Oversiktssida», og vel kor lenge han skal gjelde.
    3. Under Repository access: vel Only select repositories og infoskjerm.
    4. Under Permissions → Repository permissions: set Contents til Read and write.
    5. Klikk Generate token, kopier nøkkelen og lim han inn over.
