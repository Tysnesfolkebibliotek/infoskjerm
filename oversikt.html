    Emneordlista og Forrige bok-indeksen
    ?

    Forslaga i emne- og sjangerfelta i byggjaren kjem frå ei liste over alle emneord og sjangrar som er i bruk i avdelingane Vaksen og Born og unge. Appellfaktorar og merkelappar på karusellane kjem frå ein indeks over kva bøker hos oss som er skildra i Forrige bok. Knappen lagar begge på nytt. Gjer det ein gong iblant. Er listene meir enn to månader gamle, får du ei påminning når du opnar sida. Det tek nokre minutt og krev nøkkelen nedanfor.

    Tilgangsnøkkel for å lagre
    ?

    Alle kan sjå sida, men berre den som har ein tilgangsnøkkel kan lagre endringar. Nøkkelen blir lagra i denne nettlesaren.

    Slik lagar du ein nøkkel:

    1. Logg inn på GitHub som Tysnesfolkebibliotek og gå til github.com/settings/personal-access-tokens/new.
    2. Gje han eit namn, til dømes «Oversiktssida», og vel kor lenge han skal gjelde.
    3. Under Repository access: vel Only select repositories og infoskjerm.
    4. Under Permissions → Repository permissions: set Contents til Read and write.
    5. Klikk Generate token, kopier nøkkelen og lim han inn i feltet ovanfor.
    Ingen endringar.
